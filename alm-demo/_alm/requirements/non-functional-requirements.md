# Non-Functional Requirements

- NFR-1: Viewing, searching, and editing an already-imported recipe shall require no network access.
- NFR-2: A tag search over a 500-recipe library shall return results in under 200ms on a typical laptop.
- NFR-3: The entire library shall be a single file (or a small, fixed set of files) that a user can back up by copying it, with no external service dependency for that backup to be complete.
