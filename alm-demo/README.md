# Demo: Recipe Box

A small, **fictional** project used only to show what a filled-in `_alm/` folder actually looks like — not a real codebase (there's no `src/` here, only the `_alm/` docs a real one would have). Read [`../INSTRUCTIONS.md`](../INSTRUCTIONS.md) first for the reasoning; use this to see the pattern in practice.

Deliberately kept small — a real project's `_alm/` will usually be longer, especially `design-choices.md` and `testcases/` as more decisions get made and more increments get built. What to copy from here isn't the length, it's:
- how specific the entries are (concrete numbers and scenarios, not adjectives)
- how `design-choices.md` records *why*, not just *what*
- how `roadmap.md`'s exit criteria are things you could actually go check, not vibes
- the "what's real vs. what's aspirational" note in `project-tree.md`
